## I. TỔNG QUAN DỰ ÁN
Website được xây dựng theo chủ đề **Landing Page rạp chiếu phim cao cấp đa thể loại** mang thương hiệu **LUMIÈRE Cinema**. Trang web sở hữu phong cách thiết kế sang trọng chuẩn điện ảnh quốc tế (Tone màu vàng Gold `#d4af37` quý phái trên nền Obsidian tối `#0b0b10`, nghệ thuật chữ Cormorant Garamond kết hợp font Inter hiện đại). Toàn bộ 8 poster phim được vẽ bằng nghệ thuật CSS Gradients, giao diện tối ưu hóa thuần CSS (không phụ thuộc vào file JS ngoài).

## III. HƯỚNG DẪN KHỞI CHẠY
1. **Xem trực tiếp trên máy tính:** Nhấp đúp chuột vào file `index.html` để mở ngay trên bất kỳ trình duyệt web nào (Google Chrome, Microsoft Edge, Firefox, Safari).
2. **Xem qua Local Server:**
   ```bash
   python -m http.server 8080
   ```
   Sau đó mở trình duyệt truy cập: `http://localhost:8080`
3. **Đẩy bài lên GitHub:**
   ```bash
   git add .
   git commit -m "Hoan thien do an web rap phim Lumiere Cinema theo thang diem 10"
   git push origin main
   ```
